# prompts/

개발 단계별 프롬프트 템플릿을 두는 곳입니다. 매번 새로 쓰지 않고, 템플릿을 복사해 `{빈칸}`만 채워 바로 붙여넣습니다.

```
prompts/
└── feature-development.md   # 기능 개발 (설계 → 구현 → 테스트)
```

- **파일 하나 = 개발 단계 하나**입니다. 코드 리뷰·디버깅 등은 `code-review.md`, `debugging.md`처럼 단계별 파일로 추가합니다.
- **`{빈칸}`** 은 사용할 때 채울 자리입니다. 특정 프로젝트·스택을 템플릿 본문에 박지 말고 빈칸이나 "채워 넣은 예시"로만 둡니다.
- 이 폴더는 Claude Code 자산이 아니므로 `install.sh` 설치 대상이 아닙니다.
