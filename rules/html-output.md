# HTML 산출물 규칙

작업 리포트·API 확인용 도구 화면 등 HTML 파일을 만들 때 따른다.

## 구조
- 맨 위에 제목과 1~2문장 결론(무엇을 했고 결과가 어떤지)을 둔다.
- 상세 내용은 그 아래 표·목록으로. 수치·상태 비교는 표로 쓴다.
- 섹션은 제목(h2)으로만 나누고, 카드·박스로 감싸지 않는다.
- 한 페이지에는 목적 하나만 담는다.

## 시각
- 흰 배경, 본문 #1f2328, 보조 텍스트 #59636e, 구분선 #d1d9e0, 강조색 #0969da 하나(링크·주 버튼).
- 시스템 폰트, 본문 16px, 줄 간격 1.6, 본문 최대 폭 860px, 표는 테두리 1px·셀 여백 8px.
- 금지: 그라데이션, 반투명 유리 효과, 그림자, 6px 넘는 둥근 모서리, 애니메이션, 히어로 배너.
- 빨강·초록·노랑은 실패·성공·경고처럼 상태를 뜻할 때만 쓴다.

## 문구
- 이모지와 장식용 아이콘을 쓰지 않는다(제목·목록·버튼 모두).
- 마케팅 형용사 금지: 강력한, 완벽한, 혁신적인, 손쉽게, 원활한.
- 라벨은 짧은 명사형으로 쓴다. 예: "응답 시간" (O) / "⚡ 빠른 응답 속도" (X)
- 평가하는 말 대신 사실과 수치를 쓴다.

## 도구 화면
- 폼은 라벨을 위, 입력란을 아래에 두고 세로로 배치한다.
- 요청·응답 원문은 가공하지 않고 `<pre>`에 그대로 보여준다.
- 외부 CDN·라이브러리 없이 파일 하나로 동작하게 만든다.
